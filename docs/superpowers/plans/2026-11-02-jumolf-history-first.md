# JUMOLF : synthèse de l’historique

Objectif validé : ouvrir JUMOLF sur une lecture de toutes les séances terminées autorisées du chien, OPS et Coaching, puis proposer des entraînements documentés. Les détails individuels restent secondaires.

Choix : conserver le moteur scientifique et ses consentements ; ajouter une présentation agrégée déterministe. Les récurrences de signalements et les issues déclarées sont séparées par type de séance. Les tendances proviennent seulement de cohortes comparables existantes. Deux séances accessibles distinctes minimum pour une proposition liée à l’historique. Aucune causalité ni maîtrise canine déduite.

Accueil : choix du chien, périmètre des séances, quelques constats, deux propositions maximum, justificatifs dépliables ; détails scientifiques et démonstration repliés. Synthèse recalculée depuis les données accessibles, aucune nouvelle écriture ou persistance.

Validation : tests sur dédoublonnage, récurrences, séparation OPS/Coaching, données manquantes, preuves accessibles ; vérification syntaxique et ordre du rendu. Preview uniquement ; validation mobile avant production.
