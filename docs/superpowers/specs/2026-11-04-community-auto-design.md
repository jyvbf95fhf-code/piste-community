# Automatic completed tracks
Approved in conversation: publish future completed OPS and Coaching tracks, accepted friends audience, real geometry, no historical backfill, no duplicate session publication. Keep private ability.
Use the existing verified account source projection and account API. A persistent owner-scoped outbox retains exact commands across retries. Only sessions with a recorded completion after rollout are eligible; prepared routes and synthetic sessions are excluded. No operational person/address/notes/outcome fields enter publication. A server wrapper deduplicates attachments by author and canonical session source ID, preserving deleted/private posts on automatic replay. Existing create-post can request a restriction to private, never widen existing visibility automatically.

Coaching completion uses an authoritative searchCompletedAt stored by the existing finish-search server command and exposed only in closed projections. Old state has null, never a fabricated current date. Shared-catalogue completion refresh also runs the outbox. A live Edge v31 baseline is preserved byte-for-byte except coaching-service.mjs. GPS planned-reference fallback is omitted automatically. Retrospective OPS eligibility uses the actual intervention end, not the date it was imported. For legacy duplicate posts, private restriction covers all same-source copies.
