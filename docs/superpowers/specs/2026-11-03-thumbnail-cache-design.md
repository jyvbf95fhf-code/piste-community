# Archive thumbnail caching
User-approved scope: persist the existing aerial thumbnail of an authorized archived/prepared route on this device, reuse on return and offline, regenerate if rendered geometry changes. Keep lazy loading, geographic gaps, start/end markers, IGN attribution, account and blind-mode isolation. No server, auth, database service, V1 or main changes.

Use the existing Leaflet renderer on a cache miss. Once every aerial tile loads successfully with CORS, rasterize tile images and the existing geographic overlay into one JPEG Blob at 2× CSS resolution. Store in a separate best-effort IndexedDB cache; never store incomplete or failed imagery. Read cached image before creating a map. Key by account, rendered geometry, dimensions and renderer version. A different account cannot read a snapshot. Bound the device cache to 120 images / 12 MiB; eviction and browser storage clearing cause normal lazy regeneration. Missing storage, offline cache miss and CORS failures retain the live geographic fallback. No offline-region prefetching.
