# Tests V10.29 — lot 1

- [ ] Le conducteur ne voit pas le tracé caché pendant une session double aveugle.
- [ ] Les couches prévu, posé, réalisé, odeur et annotations sont indépendantes.
- [ ] Le délai de départ correspond à la différence entre les premiers points GPS.
- [ ] Le délai est affiché à la seconde sans devenir négatif.
- [ ] Le débrief affiche la plage de vieillissement point par point.
- [ ] Le curseur Replay affiche les deux traces jusqu'à l'heure sélectionnée.
- [ ] Les annotations n'apparaissent qu'à partir de leur heure de création.
- [ ] Le couloir olfactif évolue lorsque le curseur temporel avance.
- [ ] Une session sans traceur conserve le débrief basé sur le tracé prévu.
- [ ] La carte reste utilisable sur un écran de téléphone.
- [ ] La console du navigateur ne contient aucune erreur pendant le Replay.

## Import GPX dans une piste opérationnelle

- [ ] Un GPX de moins de 10 Mo avec au moins deux points est accepté.
- [ ] Un fichier invalide, trop volumineux ou une sixième couche est refusé clairement.
- [ ] Chaque couche affiche son nom, son type, sa couleur, sa distance et son nombre de points.
- [ ] Chaque couche peut être masquée, annotée ou retirée indépendamment.
- [ ] Les repères contenus dans le GPX apparaissent avec la couleur de leur couche.
- [ ] L'enregistrement puis la réouverture d'une fiche conserve les couches et annotations.
- [ ] Le démarrage « avec mon chien » conserve les GPX visibles en référence sur la carte GPS.
- [ ] La trace GPS du conducteur reste visuellement distincte de toutes les couches importées.
- [ ] Le retrait de l'engagement retire aussi les couches GPX de la carte en direct.
- [ ] La fiche reste utilisable sur téléphone avec cinq couches importées.
