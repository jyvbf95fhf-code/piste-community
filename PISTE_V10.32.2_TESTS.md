# Tests V10.32.2 — Coaching

## Préparation

- [ ] Le mode proposé par défaut est **Partagé**.
- [ ] Le coach peut choisir un tracé existant.
- [ ] « Créer un tracé sur la carte » ouvre le créateur puis revient au Coaching avec le nouveau tracé sélectionné.
- [ ] Le coach peut inviter un ami et lui attribuer Conducteur, Traceur, Coach ou Observateur.
- [ ] La session apparaît chez l'ami sans saisie de code.
- [ ] Le code permet toujours de rejoindre en secours.
- [ ] Une session en attente peut être supprimée depuis « Mes sessions ».

## Salle et départ

- [ ] Les rôles ont des couleurs et des lettres distinctes.
- [ ] La position GPS apparaît avant le départ.
- [ ] Le bouton de départ est réservé à l'organisateur.
- [ ] Le raccourci « Reprendre » n'est pas affiché lorsqu'on se trouve déjà dans la session.

## Carte et GPS

- [ ] Le conducteur est représenté par une flèche orientée.
- [ ] Le cercle de précision correspond à la précision GPS.
- [ ] Le trajet réel est une ligne continue et non une accumulation de gros points.
- [ ] La rotation à deux doigts fonctionne.
- [ ] La carte par défaut n'affiche aucun message « API KEY REQUIRED ».
- [ ] Un appui long ouvre le menu Objet / Attente / Indice / Repère / Danger / Zone vérifiée.
- [ ] Un déplacement ou un zoom annule l'appui long.

## Double aveugle

- [ ] Le conducteur voit sa flèche, son trajet réel, sa distance et son temps.
- [ ] Le conducteur ne voit ni tracé prévu, ni traceur, ni autres positions, ni repères cachés.
- [ ] Le coach conserve la vue complète.
- [ ] Après la fin, les données deviennent consultables dans le débrief.

## Fin et débrief

- [ ] Quand l'organisateur termine, le GPS et les minuteurs s'arrêtent sur tous les téléphones.
- [ ] L'écran noir se ferme sur tous les téléphones.
- [ ] Aucun nouveau point, message ou repère n'est accepté après la fin.
- [ ] Le débrief affiche séparément distance et durée du traceur.
- [ ] Le débrief affiche séparément distance et durée du conducteur.
- [ ] Le vieillissement de la piste est calculé entre les premiers points GPS.
- [ ] Le coach peut enregistrer un brouillon, le reprendre plus tard et publier.
- [ ] Les participants peuvent consulter le débrief publié.

## Régression

- [ ] Accueil : Pistage opérationnel et Entraînement libre réagissent.
- [ ] Le dock, la navigation et les mesures ne recouvrent pas les actions importantes.
- [ ] Aucune page blanche ou écran sombre bloqué sur Safari iPhone.
- [ ] Déconnexion nettoie le raccourci de session.
