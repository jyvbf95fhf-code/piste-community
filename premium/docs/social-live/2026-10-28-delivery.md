# Livraison — Live amis, suivi et créateur

Base commune : 3b689cd. Aucun changement V1/main/production, aucune donnée de séance supprimée/restaurée.

## Fonctionnement
- Créateur : libellés visibles sous les cinq actions du bas, sans agrandir les contrôles latéraux. Enregistrer, Fin de piste, Annuler, mode de tracé actif, Supprimer.
- Suivre : état enregistré côté serveur par compte, conservé après actualisation/reconnexion ; une modification de permission ne réinitialise pas l'abonnement.
- Amis : recherche de membres actifs par nom ou identifiant, maximum 30 résultats, sans email. L'acceptation reste indispensable pour devenir ami.
- Accès Live : par défaut pour les amitiés acceptées existantes/nouvelles, sauf retrait antérieur. Retirer un ami révoque les deux directions ; une réacceptation ne rétablit pas une permission retirée. La commande historique OPS reste cohérente avec le nouvel accès Coaching.
- La publication d'une mission OPS reste un choix distinct. Aucun partage d'une mission sensible n'est activé automatiquement ; les droits habituels concernent les publications futures, conformément au mécanisme existant.
- Live Coaching : vue observateur distante depuis la barre Live, sans rejoindre les participants ni obtenir de commandes. Normal : pose/recherche GPS ; Simple : recherche seule pour l'ami externe ; Double : état uniquement, aucune géométrie ni identifiant du Traceur. Aucun briefing, message, référence préparée ou dossier transmis.
- Badge Live : nombre de sessions/invitations autorisées disponibles. Rappel sur l'accueil et dans le centre de la cloche. Actualisation visible/manuelle et lectures automatiques bornées ; formulaires/GPS terrain non remplacés.

## Preuves locales

Base locale PGlite utilisant les migrations réelles : acceptation, suivi, idempotence, droits, retrait, réacceptation, accès serveur uniquement. Campagne navigateur nouvelle : cloche/accueil/badge, navigation observateur, Actualiser/retrait, Suivre après rechargement, recherche par nom, libellés à 320/390/430 px, Double aveugle et nettoyage à la déconnexion. Campagne OPS existante réussie (trois contextes, aucune écriture distante).

Revue indépendante : correction d'une fuite temporaire entre comptes et d'un cas follow → retrait OPS → acceptation. Aucun compte ni mission réel utilisé pour écrire des données de test.

## Validation utilisateur
Depuis deux comptes amis : démarrer un Coaching, constater le badge Live sur l'autre téléphone et ouvrir la vue observateur ; vérifier chaque mode, puis retirer l'autorisation. Tester une mission OPS explicitement partagée. GPS extérieur, reprise Safari et Push restent des validations physiques.
