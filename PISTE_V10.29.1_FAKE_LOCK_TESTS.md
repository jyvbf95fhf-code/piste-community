# Tests V10.29.1 — Mode écran verrouillé

- [ ] Le bouton reste désactivé avant le démarrage du GPS.
- [ ] Le bouton devient disponible lorsque le GPS est actif.
- [ ] L'écran sombre affiche la durée, la distance et la précision en direct.
- [ ] Les appuis accidentels sur l'écran sombre ne ferment pas le mode.
- [ ] Une pression continue de 1,4 seconde ferme le mode.
- [ ] Une pression trop courte ne ferme pas le mode.
- [ ] La mise en pause ferme le mode et désactive son bouton.
- [ ] La reprise du GPS réactive le bouton.
- [ ] La fin du suivi ferme automatiquement le mode.
- [ ] Le GPS continue d'ajouter des points lorsque le mode est affiché.
- [ ] Le fonctionnement est vérifié depuis la PWA ajoutée à l'écran d'accueil d'un iPhone.

Ce mode ne verrouille pas réellement iOS : il maintient la PWA visible et limite les
manipulations accidentelles pendant le suivi GPS.
